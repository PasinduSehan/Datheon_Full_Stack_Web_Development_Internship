## ✨ Project Highlights

### 1. Personal Developer Portfolio (`Task-01-Portfolio`)
- Mobile-first responsive layout with collapsible hamburger navigation.
- Persistent Dark/Light theme toggle saved via `localStorage`.
- Interactive project preview modals and smooth section scrolling.

### 2. Dynamic Task Manager (`Task-02-Task-Manager`)
- Full CRUD operations (Create, Read, Update, Delete) with zero server dependencies.
- Category tagging (`Work`, `Study`, `Personal`), due date tracking, live search, and status filtering (`All`, `Active`, `Completed`).
- Automatic state persistence in browser `localStorage`.

### 3. Real-Time Weather & Climate Telemetry (`Task-03-Weather-App`)
- Asynchronous city geocoding and live weather telemetry using `fetch()` and `async/await`.
- Displays temperature, humidity, wind speed, atmospheric pressure, feels-like temperature, and a 5-day forecast.
- Dynamic background gradients that adapt to current weather conditions (Sunny, Cloudy, Rainy, Night) with graceful error handling.

### 4. E-Commerce Product Catalog & Cart (`Task-04-Ecommerce-Store`)
- Fetches live product listings from **FakeStoreAPI** with category filtering and real-time search.
- Slide-out shopping cart drawer with item quantity increment/decrement, badge counter, and automated subtotal, tax (5%), and shipping calculations.
- Simulated checkout modal with order confirmation.
